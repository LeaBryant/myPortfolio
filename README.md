# myPortfolio
Updated 10.22.2026

LEA BRYANT — MY STORY WEBSITE

Copy these files into your existing myPortfolio folder:
- index.html (replace)
- app.js (replace or add, beside index.html)
- assets/style.css (replace)
- assets/lea.jpg (retain or replace with the included portrait)
- .nojekyll (add if absent)

Do not put the files inside another nested folder.
Keep your other existing assets and Git files.

Preview index.html with Live Server, or open it in your browser.
Then run from your myPortfolio terminal:
git add index.html app.js assets/style.css assets/lea.jpg .nojekyll
git commit -m "Tell my story and expand journalism and education"
git push origin main

This package updates HTML, CSS AND JavaScript; replace all three.
No npm installation or build is required.

Photography and journalism samples:
The site currently describes your experience and interests. Add your actual
photos, article links, or broadcast clips when selected. No sample gallery
or article links have been invented.
